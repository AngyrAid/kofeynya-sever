# Кофейня «Север» — проект №2

Многостраничный учебный сайт предприятия общественного питания.

## Страницы
- `index.html` — главная;
- `menu.html` — меню напитков и выпечки;
- `about.html` — концепция и ценности;
- `delivery.html` — кофе с собой;
- `contacts.html` — контакты и демонстрационная форма.

## Технологии
HTML5, CSS3, Flexbox, Grid, адаптивные медиазапросы, CSS-анимация, псевдоклассы и псевдоэлементы, JavaScript, SEO-метатеги, Open Graph, JSON-LD, `robots.txt`, `sitemap.xml`.

## Запуск
Открой папку в VS Code, открой `index.html` и запусти через расширение Live Server.

## Перед публикацией
1. Замени `https://example.com/` в canonical, Open Graph, JSON-LD, `robots.txt` и `sitemap.xml` на реальный адрес сайта.
2. Для Яндекс Метрики и Google Analytics создай свои счётчики и добавь выданный сервисом код. Аналитика специально не включена до получения настоящих ID.
3. Подбери и проверь ключевые слова через Яндекс Wordstat.
4. Проверь проект на реальном телефоне и через HTML/CSS-валидаторы.

«Север» — вымышленная кофейня. Адрес, цены и контакты демонстрационные. Форма не отправляет данные.
